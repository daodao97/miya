# Runtime scope

`runtime` 保存会话运行快照、进程与端点模型、平台探测和持久化。`tracker` 把 Agent 提供的 SnapshotSource 绑定到稳定会话身份，负责观察、去重、缓存和端点访问令牌。`web` 负责监听进程与工作目录的关联、HTTP 服务探测及访问入口。

运行环境不导入 Agent 实现、控制器或界面。Agent 提供原生运行快照，控制器负责组装；手机和桌面通过相同运行视图读取状态。HTTP 代理仍由 phone/proxy 提供，底层加密连接仍由 remote 提供。

此次收拢仅移动原 webservice 包，不改变发现策略、监听地址验证、进程归属、端点令牌或协议字段。进程探测与端点数据已在本作用域内，继续保留现有文件组织。
