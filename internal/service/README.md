# Service scope

- `protocol` 保存窗口与后台的 JSON 数据结构、错误和地址规则。旧 models 字段由本包的 LegacyModel 描述，不依赖原生 SDK。
- `client` 负责 RPC、事件队列、窗口镜像状态、远程终端，以及本机服务连接和版本切换。
- `server` 负责连接、请求排队、消息增量、发布节奏、后台锁、信号和空闲退出。Host 接入业务状态和请求，不导入控制器或 UI。
- `process` 负责后台进程启动、可执行文件信息和退出等待。
- `workspaces` 登记本机或远程服务入口、连接身份和已配对地址；它不管理 Git 项目。

控制器保留业务请求与窗口状态的适配，以及各领域组件的组装。新窗口仍在版本不同时请求忙碌后台空闲后退出，并在断开后重连；不会启动第二个会话写入者。数据目录、锁、socket、服务协议版本和后台命令行参数保持不变。
