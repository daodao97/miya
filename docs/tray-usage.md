# 菜单栏用量

菜单栏显示本机 Codex 或 Claude 账户的剩余额度。两个周期以 ` · ` 分隔。无数据时显示横线，不冒充 0% 或 100%。悬停可查看周期、重置时间和更新时间。

点击图标打开用量面板，支持 Codex / Claude 切换、手动刷新、套餐和重置时间。切换只预览账户，不修改托盘来源或当前会话。剩余额度低于或等于 20% 时进度条使用提醒色，耗尽时使用危险色。多周期和长错误信息可滚动查看，账户切换和刷新按钮固定。面板在点击外部、按 Esc 或再次点击图标时关闭。macOS 使用原生 NSPopover 的材质、阴影和图标锚点，其他桌面平台使用同一份内容。

面板中的百分比和色条表示已用额度；细刻线表示周期已过的时间比例。下方「均速」以时间比例作为均匀消耗的参考，并显示实际少用或多用的百分点。它不是请求速率或消耗预测。时间进度每分钟更新，按 CLI 返回的周期长度和精确重置时间计算，不从省略年份或带本地化文本的重置标签反推。当前 Claude CLI 只提供重置文本时保留额度和重置说明，不显示时间刻线。菜单栏数字继续表示剩余额度。

面板右上角进入“设置 → 用量”。可隐藏托盘、指定账户，或切换 Miya / Agent 单色图标。自动模式优先选择有额度的 Codex，其次 Claude。指定账户不可用时保留该选择，不自动换成其他账户。右键菜单提供用量、打开 Miya、用量设置和退出。Linux 从托盘菜单进入面板。

每三分钟刷新，关闭 macOS 主窗口后继续运行。退出 Miya 停止托盘和它启动的读取进程，独立后台中的会话继续执行。托盘是窗口进程的功能，无需等待忙碌的旧后台升级。

## 读取方式

实现参考本地 retty 的 `desktop_usage*.go` 和 `internal/agentusage`。读取模块移植到 Miya，沿用隔离的 CLI 协议测试。Codex 启动短生命周期的 `codex app-server --listen stdio://`，只读取账户、额度与重置卡。Claude 执行自身 `/usage` 命令，关闭工具、MCP、项目设置和会话持久化。两者均由 CLI 处理凭据，不直接读取认证文件。

遵循 `CODEX_HOME` 和 `CLAUDE_CONFIG_DIR`，未设置时使用默认目录。这里读取本机 CLI 账户，不使用会话的自定义启动命令。读取不创建对话、不启动工具、不保存用量历史，也不连接或重启现有的会话进程。单次读取最多 20 秒，输出上限为 1 MiB。Unix 取消操作只结束该次读取拥有的进程组。

## 重置卡

Codex 返回重置卡字段时显示可用数量和到期信息。数量来自 `availableCount`，明细不完整时明确标注已知张数。旧 CLI 缺少该字段时不显示虚构的零张。

“使用一张”先进入确认页，确认后才调用兑换接口。提交前核对账户和配置目录。明细完整时选择最早到期的可用卡，否则由 Codex 选择。结果未确认时重试沿用原来的操作标识和卡片，不自动再次兑换。后台刷新不会使用卡片。
