# 键盘快捷键

桌面端可点击侧边栏底部 Settings 旁的 `⌘` 按钮，或按 `F1` 查看说明。macOS 使用 `⌘`，Windows / Linux 对应使用 `Ctrl`。

| 操作 | macOS 快捷键 |
| --- | --- |
| 新建对话 | `⌘N` |
| 搜索和切换对话（所有项目） | `⌘K` |
| 聚焦消息输入框 | `⌘L` |
| 显示 / 隐藏侧边栏 | `⌘B` |
| 显示 / 隐藏右侧面板 | `⌘Option+B` |
| 打开设置 | `⌘,` |
| 在当前项目打开新终端标签页 | `⌘Shift+T` |
| 添加附件 | `⌘Shift+O` |
| 当前项目的下一个对话 | `Control+Tab` |
| 当前项目的上一个对话 | `Control+Shift+Tab` |
| 停止当前回复 | `⌘.` |
| 查看快捷键 | `F1` |
| 发送消息 / 运行中加入队列 | `Enter` |
| 消息换行 | `Shift+Enter` |
| 发送消息 / 运行中立即引导 | `⌘Enter` |
| 关闭弹窗或收起补全 | `Esc` |

对话搜索支持标题、项目名和会话 ID；使用 `↑` / `↓` 选择结果，`Enter` 打开，`Esc` 取消。新建和切换对话后会聚焦消息输入框，原对话的文字草稿会保留。`Control+Tab` 按当前项目侧边栏的完整排序循环切换，包括折叠列表中尚未展开的对话。

输入框补全打开时，`Enter` 优先选择补全项；`⌘Enter` 不会绕过补全直接发送。弹窗打开时，全局快捷键暂停，避免误操作背后的对话。复制、剪切、粘贴、撤销、重做，以及文件编辑器的 `⌘S` 保存，沿用各自输入控件的行为。
