## Checks

- Built native arm64 macOS app and universal app/DMG with the new scripts.
  `codesign --verify --deep --strict` passed for the app and the read-only mounted
  DMG's app. `lipo` reported arm64 and x86_64 in both the executable and bundled
  terminal library. DMG was detached afterward.
- `verify-package.py` checked actual macOS, iOS simulator, unsigned device IPA and
  Android APK metadata. `aapt2 dump badging` and network-resource XML inspection,
  plus `apksigner verify --verbose`, passed for the APK (v2 signature).
- Both native and universal app processes launched in isolation and started a
  separate service from their own bundle. The final universal service reported
  protocol 2, release `0.1.0`, correct executable path, `busy: false`, and state.
  `run-isolated.sh`'s detached launch and long socket path handling were exercised.
  Test windows received normal application quit requests, then both isolated
  services were stopped with `scripts/run-isolated.sh stop`; subsequent status
  reported no isolated services. No process was force-killed.
- `go build ./...` passed using the shared Go cache and `build/.tmp`.
- `go test ./tests/integration/...` passed with the temp directory confined under
  `build/.tmp` and `GIT_CEILING_DIRECTORIES` set to that root. Without that ceiling,
  `TestAutomationWorktreeNeedsRepository` discovers the enclosing worktree and
  fails; this is a consequence of putting test temp directories inside a Git repo.
- Guarded-overlay tests check typed plist/URL scheme serialization, selfupdate
  flags, profile-prefix expansion and rejection of unauthorized Keychain groups.
  The NSGo APK encoder tests also pass with the overlay. Their optional apksigner check needs a real JDK directory first in PATH: the macOS `/usr/bin/java` launcher makes that test infer the wrong JAVA_HOME. Direct SDK apksigner verification of the product APK also passed.
- Linux arm64 server archive built, with the same selfupdate marker.
- Shell syntax, workflow/config YAML parsing and the CI unpublished-fork rejection
  were checked. No GitHub Actions run, push, merge or application installation was
  performed. Large verified artifacts are removed after inspection.

## Still requires external validation

The Mac was screen-locked. Computer Use could not capture/inspect the window, so
process/service startup is verified, but visual rendering and interactions are
not. No device installation was requested or performed. Signed iOS APNs delivery,
Face ID, QR/microphone behavior, legacy Keychain access and Live Activities push
updates need appropriately provisioned devices. Developer ID signing/notarization
and App Store distribution were not exercised without configured credentials.
CI remains gated on publication of the documented NSGo fork/version. The source
compatibility overlay must be retired or adapted when those hooks land upstream.
