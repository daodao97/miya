# 手机端多个桌面

手机保存多个已配对桌面，每次使用其中一个。抽屉顶部的桌面名称可打开桌面列表；设置中也有「管理桌面」和「添加桌面」入口。

- 添加：扫码或粘贴另一个桌面的连接码。打开添加页面、取消扫码或输入无效连接码都不会断开当前桌面。有效连接会保存，暂时离线时仍可从列表重试。
- 切换：点击已保存的桌面。保留其他配对、对话缓存及各自的消息选项；同一次运行中还会保留草稿、附件和打开的对话。
- 移除：在对应桌面的操作菜单中选择「移除桌面」。只删除该桌面的配对及本地缓存；移除当前桌面后选择剩余桌面，没有剩余桌面时回到扫码页。不改变手机全局通知开关。

配对列表、连接凭证和最后选中的桌面保存在系统钥匙串的 `desktops-v1` 条目中，界面及文件名不展示连接码。旧 `desktop-link` 自动迁移，只有新列表保存成功才删除旧条目。迁移保留原连接字符串，因此原有缓存不会丢失。旧版全局消息选项只迁入原桌面。

各桌面的缓存仍位于应用数据目录下独立的哈希目录中，消息选项存入同一目录。切换会使旧连接的回调失效，清空当前视图、审批输入及命令列表，再读取目标桌面的缓存。桌面 ID 和对话运行时 ID 不能跨桌面混用。

旧桌面的通知通过持久会话标识匹配已保存桌面的缓存。无法确定来源的旧通知会打开桌面列表让用户选择，避免仅按数字会话 ID 打开另一台桌面的对话。

验证：`go test -race . -run 'TestMobile(Desktop|NotificationsSelect|Disk)'` 覆盖迁移、持久化、缓存隔离、移除、草稿附件与通知归属。`MIYA_SNAPSHOT=/tmp/miya-desktops go test . -run TestMobileDesktopManagerNavigationAndSwitch` 可导出桌面列表截图。
