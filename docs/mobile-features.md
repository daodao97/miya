# 手机端对话功能

手机与桌面使用远程协议 v5，两端需一起更新。桌面后台仍负责实际执行任务，手机离线不会终止已经发送的任务。Codex 共用一个后台进程，切换项目或在其他项目发送消息不会停止原项目的任务，正在运行的 Claude Code 对话也会在原项目里继续运行；后台对话继续同步输出、处理审批和执行排队消息。后台仍有任务时，服务会等待它们结束后再更新。

## 首页与会话

桌面与手机的消息列表中，当前回合的 activities 分组保持展开，运行期间不能折叠；回合结束后默认折叠，仍可手动展开查看。重新加载已完成的历史消息时默认折叠，不依据历史条目残留的运行状态自动展开。

手机界面跟随系统字号；正文、标签和文本行会随字号调整，常用按钮保留至少 44 点的触控区域。会话输入框支持拖动交互式收起键盘，空间较小时可通过 Agent 图标进入模型与权限设置。页面切换带转场，返回动画结束后才释放会话内容，并遵循系统的减少动态效果设置。 iOS 滚动区域触边后支持阻尼回弹，横向表格触边不会带动整页；回弹仅移动区域内的内容，顶部导航与底部输入框保持原位。键盘弹出、收起按系统动画曲线逐帧调整内容高度，交互式收起时跟随手指；开启减少动态效果时不使用弹性回弹。

首页默认展示所有项目的会话，按「待审批」「运行中」「未读」「最近会话」分组，同组按最近活动排序。每个会话显示所属项目、Agent 和状态，点击即可继续对话。侧边栏可筛选单个项目，点击「全部会话」恢复全部项目。

项目和会话的最近活动时间只随实际对话更新，例如发送消息或开始新回合。点击打开会话、查看历史和编辑未发送的草稿不会更新时间，也不会因此调整顺序。

侧边栏展示「进行中」「已完成」、项目会话列表、Agent 额度和桌面连接管理。「进行中」汇总所有项目正在执行的会话；「已完成」展示尚未查看的完成结果，读取中的历史会话不计入两组。两端共用分组组件和筛选、去重、排序规则，不受项目折叠或五条会话限制；活动时间相同时按项目顺序排列，切换项目不会换位。点击活动会话直接进入所属项目并收起侧边栏。完成未读状态与桌面同步，不依赖手机推送是否开启；旧后台暂时使用手机原有的通知未读状态，后台升级后自动使用共享状态。侧边栏背景和主页遮罩覆盖顶部状态栏及底部手势区域，随拖动与开关动画同步移动；文字与按钮继续避开刘海、状态栏和底部手势区域。

会话右上角「更多」打开底部操作表，操作文字居中，每行用细分隔线分开，「取消」独立固定在下方。支持明暗主题和系统大字体；横屏或空间不足时仅操作列表滚动。点击取消或遮罩保留当前会话和草稿，离线时需要连接的操作不可点。

点击「新会话」进入独立的新建页面，默认使用当前筛选的项目，未筛选时使用桌面当前项目；新建页面可以更换项目和 Agent。返回后显示会话列表。缓存中的会话在连接恢复前也可浏览。

新对话的首条消息在点击发送后立即显示，并标注「发送中」。电脑确认接收后，保留消息和图片预览直到正式对话内容同步回来，避免等待期间列表空白。发送失败会保留输入内容和附件以便重试；本地预览不写入历史缓存，也不会在同步后重复显示。

无需填写内容的 MCP 确认直接在会话卡片中显示操作按钮；Computer Use 应用授权可直接选择「允许一次」「拒绝」或「此对话始终允许」。需要填写字段或打开浏览器的请求保留详情页。可用的允许按钮使用蓝色，禁用或提交中的按钮使用灰色。

桌面授权需要填写信息时，进入单窗口操作页后可在输入栏下方直接点原生允许或拒绝按钮。后台处理完该授权后自动返回会话，无需手动关闭页面再确认一次；输入错误时保留操作页供重试。

输入 `@` 可按标题或编号搜索所有项目的对话，候选项显示所属项目。选中后，对话名标签嵌在文字中，正文可直接接在标签后面，空间不足时一起换行。标签可通过退格、选中删除、剪切和撤销来编辑；复制粘贴保留引用编号。发送后的消息气泡也在原文位置显示对话名标签，后台整理的引用上下文不展开显示。桌面和手机使用相同样式。

输入框轻点进入文字编辑；长按输入框约半秒开始语音输入，麦克风启动后轻震动一次，松手后等待识别完成，在原来的光标或选区插入文字。默认不自动发送；可在「设置 → 语音输入」开启「说完直接发送」，松手并识别完成后按普通消息流程发送当前草稿，录音期间的提前定稿不会触发发送。开关仅保存在本机，每次录音使用开始时的选项。输入框下方不显示常驻提示文字或编辑图标。录音和识别期间可点「取消」，切换页面、会话、电脑或退到后台也会取消；取消、识别失败、草稿被修改时不发送，断线或发送失败时保留文字供重试。

语音输入使用 voicekey 的微信输入法云端协议，手机采集 16 kHz 单声道 PCM，由共享 Go 层编码为 Opus 并加密直连微信云端；松手后等待整理后的定稿。不经过桌面、不保存录音文件，也不下载本地模型。设备注册信息保存在应用私有目录，不需要登录微信。首次使用需要麦克风权限，可提前在「设置 → 语音输入」中授权；授权弹窗打断长按时，允许后重新按住即可。单次录音最多 60 秒，松手后的定稿等待有超时保护。该功能只需更新 iOS 应用，无需更新桌面后台。

手机设置采用分组列表，首页显示语言、语音识别渠道、桌面连接、会话和通知设置。语言和语音进入独立子页，支持返回及边缘返回手势；语言仍仅在本机保存。设置行整行可点，默认至少 52 点高，大字体时将当前值放到标题下方。浅色使用灰底白色分组，深色使用黑底深灰分组，说明文字位于分组下方。

发送后的图片在消息中显示缩略图。手机按需通过配对连接取得当前会话图片的预览，并缓存到本机；重新打开会话时可直接显示已缓存的图片。缩略图最长边为 640 像素，发送给 Agent 的原图不受影响。此功能需要手机端和桌面后台均更新。新端之间通过独立的二进制附件通道传输原图和缩略图，聊天控制消息不携带大块 base64；旧端保留原格式。协商、限制和验证见 [二进制附件通道](remote-attachments.md)。

消息文字需长按约半秒后才进入 iOS 原生选区与复制菜单，成功选中时提供一次轻触觉反馈。两侧手柄支持独立拖动、向外扩展和向内缩小选区，可跨段选择；手柄触控优先于消息滚动和屏幕边缘返回。普通点击不会进入选区；滑动仍用于滚动消息，链接点击和输入框编辑保持正常。复制同时提供纯文本、HTML 和 Markdown；复制后清除消息选区并关闭菜单。输入框中的复制保留选区，便于继续编辑。

## 电脑上的项目文件

首页和会话顶部的「更多 → 项目文件」打开当前项目的文件目录。手机使用 iOS 原生底部 Sheet，默认大尺寸，可拖到半屏或下拉关闭；Sheet 内保留目录、前进、后退、刷新与下载操作。

电脑通过已有的 Tailcat 私有通道提供只读 HTTP 文件服务。HTML 在 WKWebView 中直接渲染，相对路径和以 `/` 开头的项目资源路径均可加载；图片、PDF 等使用浏览器能力查看，源码和 Markdown 显示为文本。其他格式和主动下载的文件交给系统 Quick Look 或分享面板，可保存到「文件」。传输支持 Range，不受聊天消息大小限制。

浏览范围限制在所选项目，禁止写入和通过符号链接访问项目外的文件。手机代理仅监听本机回环地址，关闭 Sheet 即关闭该次访问并清理临时下载。两端均需更新；电脑有任务时，旧后台会在空闲后自动更新。

## 会话中的远程桌面

接管授权卡直接预览目标授权窗口，并显示该窗口原生按钮及其可用状态。点预览进入单窗口界面填写密码；明确允许或拒绝后，确认目标窗口已关闭才恢复任务。密码不进入聊天记录。已有会话的「更多 → 远程桌面」保留需单独确认的主屏幕操作。关闭、断线或十分钟到期后撤销控制。Agent 可用 `request_desktop_control` 发起请求，并用应用名和窗口标题定位目标。系统授权、支持范围和验证见[远程桌面](remote-desktop.md)。

## 电脑上的 Web 服务

对话顶部的「更多 → Web 服务」展示经核验属于本对话的 HTTP 服务，点击即可在原生 Sheet 中预览。Codex 通过原生后台终端取得进程证据，Claude 通过后台工作事件和独占会话执行进程取得证据；两者共用运行态、系统进程和端口核验，不再以相同工作目录推定属于同一对话。

「更多 → 后台运行」可查看原生后台任务、系统进程、非 HTTP 端口和最近核验时间。手机页面打开时刷新，并每五秒更新；桌面右侧面板提供同一份「后台运行」视图，Agent 可通过只读 `runtime_info` 查询自己的运行态。后台 Bash 可以在主回复完成后继续运行，回合状态和后台工作状态分别处理。

首页的 Web 页面提供项目总览，先聚合已核验的对话服务，再列出目录扫描发现的项目候选，明确标注未确认归属。候选发现需要电脑提供 `lsof`（macOS 自带）。手动输入端口继续可用。点击已归属服务时会重新核验原进程身份和监听端点，防止端口被其他进程复用。

运行信息失联时显示待核验及上次时间；桌面后台重启后，保存的进程记录也须重新核验。无法证明归属的脱离进程不会自动归入某个对话。当前系统进程核验支持 macOS、Linux，其他系统保留原生任务信息并提示能力边界。新能力单独协商，两端均需更新；旧端保持原有手动/项目查看方式。设计和交付边界见[通用对话运行态](conversation-runtime.md)。

访问通过已有配对通道转发到电脑的本机回环地址，电脑上的服务无需监听局域网或公网。支持相对路径、以 `/` 开头的资源、表单/API 请求、Cookie、同端口本机重定向、SSE 和 WebSocket（如开发服务器的热更新）。关闭 Sheet 会停止该次代理及 WebSocket 连接；切换电脑也会结束该次访问。此能力单独协商，两端均需更新，旧后台显示更新提示。

目前输入的是 HTTP 端口，不支持 HTTPS 服务；页面或脚本中写死的其他 `localhost` 地址和其他端口不会自动转发，网站应使用相对地址或当前页面的 origin。此入口访问电脑上的服务，与项目文件的只读浏览不同，页面上的表单和操作会正常提交给该服务。

## 连接重试与失败

Codex 上游断线并自动重试时，对话底部显示带动画的「正在重连…」，上游提供次数时显示如 `4/5`。等待期间保留已经收到的内容；恢复模型输出后回到工作状态。重试最终失败时，停止运行指示并在消息中保留具体错误，不会只留下转圈。桌面与手机使用同一套显示逻辑。

错误卡片的「重试回复」会从最后一条用户消息重新开始，替换该消息及其后的失败回复，保留更早的对话、原请求的附件和会话引用。它不会追加「继续」，也不会改变输入框中尚未发送的草稿。与编辑消息相同，重试不会撤销已经改动的本地文件；回退失败时保留原对话并显示原因。

## 模型、推理强度与权限

侧边抽屉显示当前连接电脑上已有额度数据的 Agent，用量环与电脑端使用同一份账户额度。点击 Agent 可查看各周期的已用百分比和重置时间（手机本地时区）。打开抽屉会请求刷新，后续随电脑数据同步；缺少额度数据的 Agent 隐藏，全部缺少时不显示这一栏。这里只查看额度，不切换发送消息所用的 Agent。

点击输入框左侧的 Agent 图标或右侧的推理强度，可进入「对话设置」；侧边抽屉右上角「设置 → 模型与权限」也能进入。首页按模型、推理强度、权限模式显示当前值；点入分组单选列表，选择后返回首页，返回未选择时保留原值。使用与手机设置相同的整行触控、分隔线、明暗主题和大字体布局。模型和可用推理强度来自桌面当前 Agent 的实际选项。

选择保存在手机本地，并随每条新消息发送，不修改电脑端的默认设置。切换模型会恢复该模型默认强度。点击「使用电脑默认」可取消手机的覆盖设置。新选择不改变已经运行的回合；排队消息保留发送时的选择。

## 排队与立即引导

当前会话执行中，有草稿时主发送按钮显示「加入队列」，旁边的「立即引导」将消息插入当前回合。Agent 尚不能接收引导时自动进入队列。草稿为空时，主按钮仍是「×」停止按钮。

待发送消息显示在输入框上方，可以删除或立即引导。当前回合被手动停止时，队列会暂停，点击「继续发送」恢复。执行、队列与附件都由桌面后台持有。

## 审批与表单

允许或拒绝普通执行请求可直接在会话里操作。问题和 MCP 表单通过「填写回答」「处理表单」打开独立页面：

- 问题支持选项、自由回答、保密输入和跳过。
- 表单支持字符串、数值、整数、布尔值和枚举，并复用桌面端的 schema 校验。
- URL 请求由用户在浏览器完成后明确确认。
- 已有的 Computer Use 应用访问请求可选择「此会话始终允许」，范围与桌面一致，后台重启后失效。

回复须经桌面确认后才关闭；断线和校验失败会保留输入。请求已由其他客户端处理时，过期页面不会再次提交。保密回答仅保存在内存中。

角标和未读通知见 [通知说明](notifications.md)。

## 共享记忆

侧边栏的「共享记忆」可查看当前项目的记忆与用户偏好，包括正文、类型、状态、信息时间、有效期和可用的来源会话。手机端仅支持查看；新增、编辑、忘记和提升到项目文件请使用桌面端 **Settings → 记忆**。

该入口通过桌面能力字段单独协商，不改变协议 v5 的已有消息含义。旧桌面会显示更新提示；列表只在明确请求时传输，普通状态广播不携带记忆库。切换连接的桌面会清空列表。遗忘会移除 Miya 保存的记忆正文并停止召回，无法删除 Agent 已有历史或备份。当前只提供显式记忆与本地关键词查询，自动注入和提炼尚未启用。完整设计和交付状态见 [共享记忆](memory.md)。
