# NSGo test migration

Inventory baseline: `3975780`. This ledger covers every top-level test in files importing MyGo or the four legacy UI packages, every test next to those packages, and indirect users of their shared integration fixtures. There are 456 direct/package-local entries and 80 additional fixture-dependent entries. The opt-in native `TestMain` harness is included as one entry.

| Ported | Rewritten without UI | Covered by existing NSGo tests | Obsolete | Total |
| ---: | ---: | ---: | ---: | ---: |
| 108 | 232 | 163 | 33 | 536 |

“Ported” means the behavior now has a new nsgotest replacement; several original tests can share a focused replacement. “Rewritten” keeps controller, service, presentation or phone-state assertions in the default suite without rendering. “Covered” identifies an existing retained-view test. “Obsolete” retires a concrete MyGo renderer/router/platform contract or a feature explicitly outside the current NSGo phone scope; the historical source is now removed after recording its replacement here.

Phase 5 removed the historical integration files, package-local MyGo tests, old native fixture and all four legacy UI packages. Domain replacements now run without migration tags. The ledger retains historical file/test identifiers from baseline `3975780`; links in its first column refer to those deleted sources at that baseline. Replacement links point to current tests.

Framework-free phone regressions exercise `internal/phone/client`. Retained UI tests live next to `nsui`, `nsmobile`, `nschat` and `nsrequests`. Boundary tests scan the NSGo packages, forbid provider/controller dependencies, and reject retired imports across all integration sources and platforms. Platform-entry tests select one NSGo entry with no custom build tags.

The ports exposed and fixed: badge revision leaking across desktop switches; incomplete legacy pairing-key cleanup; rich-editor key capture swallowing shell commands; missing report/thread-link routing; missing prompt timestamps and diff counts; elapsed labels freezing between model updates; turn-status movement when diff counts appear; a resumable lease surviving manual disconnect; and long histories pushing the phone composer below the viewport.

Native device drawing, platform permission prompts and real provider CLIs remain outside headless verification. MyGo screenshot/pixel/drawer-only checks and unsupported native bridge contracts are individually identified below. Existing opt-in network/provider tests retain their normal environment gates.

Verification results and scratch-deletion procedure appear after the ledger.
